Original mission

You're editing the game's own mission as a draft. The app can't replace original stages, so these edits stay here. To put a version in the game, copy it to one of your 20 custom stages.

In the game

    Rewards from the template

    Rewards, enemies and drop chances come from the template mission and can't be changed yet. First clear has its own reward group, so it pays out even if you've cleared the original.

    How to put it in the game
    1. Press Export for the game. The preview lists exactly which custom stages go in the pack; only stages with Show in game on are included.
    2. Get the file onto your phone, for example in Files › On My iPhone › Blazing:Rebirth.
    3. In the app, open Forge Studio › Stages, choose Import stages and pick the file.
    4. Build the mod, close the game completely and open it again.
    5. Your stage is under Emergency Missions. The original mission stays as it is.
    Stage ID

    The app gives each stage ID one of its 20 stage slots for good. Keep the same ID when you update a stage, so it replaces the old version instead of taking a new slot. Hiding a stage doesn't free its slot.

    Map

    Pull whole maps, with all their waves and enemies, from any mission onto the end of this stage. Good for boss rushes; remove any waves or maps you don't want afterwards.

    Export for the game

    Only configured custom stages with Show in game on go in the pack, in slot order. The pack holds just the stage files: the app already has each template's maps, enemies and art, and it rejects packs with extra files.
