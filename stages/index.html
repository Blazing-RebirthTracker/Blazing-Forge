In-game template

This version never overwrites stock stages. Edit this game-ready template and your edit goes straight into a custom copy in your first empty slot, which is what gets exported.

In the game

    Markers on this map

    Pick a marker, then drag it on the field or use the arrow keys. Entry points are shared: moving one moves every spawn that uses it, in every wave and enemy set.

    Rewards from the template

    Rewards, enemies and drop chances come from the template mission and can't be changed in a game export. First clear has its own reward group, so it pays out even if you've cleared the original.

    How to put it in the game
    1. Press Export enabled stages. The preview lists exactly which definitions go in the pack and why the others are left out.
    2. Get the file onto your phone, for example in Files › On My iPhone › Blazing:Rebirth.
    3. In the app, open Forge Studio › Stages, choose Import stages and pick the file.
    4. Build the mod, close the game completely and open it again.
    5. Your stage is under Emergency Missions. The original mission stays as it is.
    Advanced details

    The app gives each localId one permanent slot. Keep the same localId when you update a stage, so it replaces the old version instead of taking a new slot. Switching a stage off doesn't free its slot.

    The three supplied event quests keep their own reserved stage and mission IDs. They never use the custom slots, and the game packs on the other tabs never include them. Change each floor’s background and floor layout, reorder floors, and edit markers, enemies, stats, difficulty and rewards here, then use Export Kirito project for developer: the developer compiles and validates your edits into a build.
